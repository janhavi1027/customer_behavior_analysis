# DESCRIPTION
End-to-end data analytics project using Python, SQL (PostgreSQL), and Power BI to analyze customer sales and behavior through EDA, SQL queries, and interactive dashboards.

## OVERVIEW
This project demonstrates an end-to-end data analytics workflow using Python, SQL, and Power BI. The objective is to analyze customer sales and behavior data, clean and transform raw data, answer business questions using SQL, and present insights through interactive dashboards.

The project is designed to reflect real-world data analyst responsibilities and is suitable for professional and academic portfolios.

---

- Customer Shopping Behavior Dataset (CSV format)
- Structured transactional and customer-level data

- age, age_group
- gender
- category, item_purchased
- purchase_amount

## Project Workflow

### 1. Data Loading
- Loaded the dataset into Python using Pandas.
- Verified schema, data types, and basic statistics.

### 2. Exploratory Data Analysis (EDA)
- Analyzed customer demographics and purchasing behavior.
- Identified trends in sales, subscription status, and payment methods.
- Visualized distributions and relationships using Python.

### 3. Data Cleaning
- Handled missing and inconsistent values.
- Standardized column names and formats.
- Ensured correct data types for numerical and categorical fields.

### 4. SQL Analysis (PostgreSQL)
- Imported cleaned data into a PostgreSQL database.
- Executed SQL queries to answer key business questions:
  - What is the total revenue generated by male vs. female customers?
  - Which customers used a discount but still spent more than the average purchase amount? 
  - Which are the top 5 products with the highest average review rating?
  - Compare the average Purchase Amounts between Standard and Express Shipping?
  - Do subscribed customers spend more? Compare average spend and total revenue between subscribers and non-subscribers.
  - Which 5 products have the highest percentage of purchases with discounts applied?
  - what percentage of total revenue come from discounted vs non-discounted purchases?
  - Segment customers into New, Returning, and Loyal based on their total number of previous purchases, and show the count of each segment.
  - What are the top 3 most purchased products within each category?
  - Are customers who are repeat buyers (more than 5 previous purchases) also likely to subscribe?
  - What is the revenue contribution of each age group? 

### 5. Power BI Dashboard
- Built a multi-page interactive dashboard including:
  - Sales Overview
  - Customer Demographics
  - Customer Behavior and Engagement
- Implemented KPI cards, charts, and slicers for dynamic analysis.
